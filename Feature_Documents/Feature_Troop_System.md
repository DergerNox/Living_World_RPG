
# Troop System

## Class
- `Troop`

## Description
- Represents individual combat units with stats like damage, health, armor, speed, level, rank, and cost.
- Supports leveling up and rank updates.
- Loads troop images based on type and rank.

## Completeness
90% - Highly detailed with types, ranks, stats, and leveling; nearly complete but may need visual assets.

## Priority
Medium - Almost complete, focus on integration and polish.
