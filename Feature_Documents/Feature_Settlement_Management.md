# Settlement Management

## Classes
- `Town`
- `Castle`
- `Village`

## Description
- Settlements have properties like position, faction, garrison size, visitors, parties, buildings, and available units.
- Towns manage troops available for recruitment and building queues.

## Completeness
70% - Town class is well-developed; other settlements likely similar, but full integration and mechanics (e.g., building construction) are partial.

## Priority
Medium - Needs economy integration.

## Potential Improvements
- Implement building construction and upgrades.
- Add economic systems (trade, taxes).
- Include settlement events (e.g., sieges, growth).
