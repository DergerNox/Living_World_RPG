# Battle System

## Class
- `Battle`

## Description
- Manages combat between parties and individual troops.
- The `BattleIndividual` method simulates combat between two troops until one dies.
- The `BattleParties` method simulates battles between attacking and defending parties by iterating through their troops.

## Completeness
50% - Basic combat logic exists, but lacks UI, advanced tactics, or integration with the game world.

## Priority
High - Core gameplay loop requires functional combat.

## Potential Improvements
- Add turn-based or real-time battle UI.
- Implement terrain effects on combat.
- Include special abilities and formations for troops.
- Integrate battles with the world map.
