# Inventory and Equipment System

## Overview
The Inventory and Equipment System is a proposed feature for the Living World RPG that allows characters and parties to manage items, weapons, armor, and consumables.

## Description
- Allow characters and parties to carry and manage items, weapons, armor, and consumables.
- Implement equipment slots and stat bonuses from items.
- Include inventory management with weight limits and item stacking.

## Priority
High - Core RPG mechanic for character customization and progression.

## Implementation Notes
- Create Item classes for different types (weapons, armor, consumables).
- Implement inventory UI with drag-and-drop functionality.
- Add equipment slots on character models with stat calculations.
